# python-mini-projects

Three beginner Python games I built while learning the basics: variables, loops, conditionals, user input, and the random module.

## Projects

| File     |       What it does |

| dice_roller.py | Rolls a die and shows the result |
| number_guessing.py | The computer picks a random number and you keep guessing until you get it |
| rock_paper_scissors.py | Play rock paper scissors against the computer |

## How to run

You need Python 3 installed. In a terminal, run:

python dice_roller.py
python number_guessing.py
python rock_paper_scissors.py
